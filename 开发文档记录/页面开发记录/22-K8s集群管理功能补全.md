## 一、Pod Exec 终端（`components/PodExecTerminal.tsx`）

与 PodLogViewer 同一套一次性 token 会话（`POST exec/session` → WS），帧协议：
上行 `{type:"input",data}` → stdin；下行 `{type:"output",data}` ← stdout/stderr。

交互设计（行式终端，不引入 xterm——遵守项目「WebSSH 用 @wterm/react、不自引入终端库」的约定精神）：
- 输出区黑底滚动 + 输入行（连接后可用）
- **↑/↓ 命令历史**（最近 50 条）、**Ctrl+C 发送 \x03 中断**、回车提交
- 容器切换（连接前可选）、清屏、输出环形裁剪 200K 字符防 DOM 爆炸
- 状态徽标（连接中/已连接/已断开/错误）；空闲 5 分钟服务端自动断开提示

## 二、YAML 工作台（`components/ClusterYamlWorkbench.tsx`）

两步安全流（对标 Rancher YAML 部署）：
1. **试运行**——后端 server-side dry-run，多文档（`---` 分隔，≤20 个）逐条返回 ✅/❌ 与错误详情
2. **应用到集群**——仅试运行通过后可用；操作写入集群审计日志

预置模板：Deployment / Service / Namespace 一键填充。

## 三、两个新 Tab

**命名空间**：列表（名称可点展开用量）+ 创建 Modal（名称校验 `^[a-z0-9]([a-z0-9-]*[a-z0-9])?$`、
标签 k=v 解析、配额预设 small/medium/large）+ 资源用量卡（ResourceQuota 聚合）。

**操作审计**：时间/操作人/动作/对象/结果/风险等级，最近 100 条。

## 四、顶部全局搜索

详情页头部搜索框：后端并发搜 Pod/Deployment/StatefulSet/DaemonSet/Service/ConfigMap/Secret/Ingress，
结果抽屉点击跳转（Pod → Pods Tab，其余 → 资源浏览 Tab）。

## 五、既有 Tab 的功能补全

- **节点**：操作列 +「标签/污点」编辑抽屉（打开时回填现有值；`-key` 行表示删除；
  taints 全量替换语义与后端一致；kubernetes.io 前缀受后端保护已在 UI 提示）；
  节点详情从 JSON dump 升级为结构化（属性表 + Pod 分布 + Taints）
- **工作负载**：+改镜像 Modal（触发滚动发布）、+暂停/恢复（缩到 0 并记忆）、
  +滚动发布状态抽屉（进度条 + 5 秒自动刷新）；**CronJob 行专属**：手动触发、
  挂起/恢复、执行记录（Jobs 列表抽屉）
- **Pods**：+「终端」按钮（exec），容器清单与日志抽屉共用同一份 Pod 详情查询
- **资源浏览**：PVC 行 +扩容 Modal（仅扩不可缩提示）；Ingress 事件抽屉顶部 +TLS
  状态摘要（Secret/域名/到期天数）；通用 +关联资源抽屉
