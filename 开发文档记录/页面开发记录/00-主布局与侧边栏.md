# 主布局 & 侧边栏开发记录

**文件**：`frontend/src/components/layout/MainLayout.tsx`  
**状态**：✅ 完成（折叠动画、hover 展开、底部按钮）

---

## 功能说明

| 功能 | 实现方式 |
|---|---|
| 6 大模块侧边栏导航 | antd `Menu` inline 模式，约 27 个入口 |
| 底部「收起/展开」按钮 | 点击切换 `isCollapsed` 锁定态 |
| hover 临时展开 | `isHovered` 状态，进入展开、离开收回 |
| 折叠时重置子菜单 | `openKeys` 手动管理，折叠/离开时重置为当前活跃分组 |
| 文字隐藏 | `opacity + translateX`，非 display:none，保留占位 |
| 折叠动画 | `all 0.3s cubic-bezier(0.645, 0.045, 0.355, 1)` |
| 顶栏用户下拉 | 显示用户名，退出登录 |

---

## 状态设计

```
isCollapsed   — 锁定折叠态（点击按钮切换）
isHovered     — hover 临时展开态（鼠标进入/离开侧边栏）

visualCollapsed = isCollapsed && !isHovered
               ↑ 用于控制 Sider collapsed 属性和文字 opacity
```

---

## 关键实现细节

### openKeys 手动管理
antd Menu 默认 `openKeys` 受控后需手动维护。折叠/hover 离开时重置为
`activeGroup`（当前路径的一级分组），避免 hover 唤醒时展开一堆历史子菜单。

### 弹出子菜单问题
`inlineCollapsed={true}` 时 antd Menu 内置 hover 弹出行为比 React `onMouseEnter` 更早触发，
用 `index.css` 全局压掉：
```css
.ant-menu-submenu-popup { display: none !important; }
```
折叠态 hover 展开后显示内联子菜单，不需要浮动弹出层。

### 动画抖动修复
antd Sider 折叠时同时变化 `width`/`min-width`/`max-width`，
只写 `transition: 'width'` 会导致其他属性瞬间跳变。
改为 `transition: 'all 0.3s ...'` 后动画平滑。
