# 03-06 - 资产管理四大部分（虚拟机、凭证、域名、证书）升级落地

> 更新时间：2026-08-05

---

## 优化特征总结

### 1. 🔑 凭证管理 (`/assets/credentials`)
- 激活“导出凭证”按钮，弹窗支持 **“合规审计脱敏表 (CSV)”** 与 **“口令加密安全备份包 (.opspilot-cred)”** 两种导出模式；
- 支持单条 SSH 密钥 `.pem` 文件的安全高危确认下载。

### 2. 🌐 域名管理 (`/assets/domains`)
- 表单新增 `启用 ACME 自动证书申请` 联动区域；开启保存后弹出 Modal 引导快捷跳转至 `/assets/certificates`；
- 表格增加 `ACME 自动签发` 蓝色 Badge 穿透显示；
- DNS 解析记录 Drawer 引入 `Input.Search` 搜索框与记录类型 Filter 筛选，零延迟检索。

### 3. 📜 证书管理 (`/assets/certificates`)
- 表格列“部署目标”升级为 **「部署任务」**，带图标 Stack（🖥️ 主机 SSH / ☁️ 云 CDN/ALB / ☸️ K8s Secret）；
- 升级为 **「证书自动化部署任务中心」抽屉**，包含 3 大多模态 Tab 分发：
  - **Linux 主机**：支持多主机分发、落盘路径、系统 reload 脚本；
  - **云服务商**：支持阿里云/腾讯云 API 凭证与 CDN/ALB 实例关联；
  - **Kubernetes**：支持纳管集群、Namespace 与 TLS Secret 名称一键推送。
