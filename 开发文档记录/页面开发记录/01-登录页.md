# 登录页开发记录

**路由**：`/login`  
**文件**：`frontend/src/pages/login/index.tsx`  
**状态**：✅ 完成

---

## 功能说明

| 功能 | 实现方式 |
|---|---|
| 动态标题/副标题 | 调用 `GET /api/settings/login-page`（免鉴权）|
| 用户名密码登录 | `POST /api/auth/login`，返回 JWT Bearer Token |
| Token 持久化 | Zustand + localStorage，key: `opspilot-auth` |
| 登录成功跳转 | `navigate('/', { replace: true })` |
| 已登录访问登录页 | `GuestGuard` 自动跳转 `/` |
| 未登录访问其他页 | `AuthGuard` 自动跳转 `/login` |
| 密码错误提示 | 内联 `Alert`（区分 401 和其他错误） |
| 忘记密码 | 点击弹出居中 Modal，提示联系管理员 |

## 关键实现细节

### 错误处理
```
密码错误（401/400）→ "用户名或密码错误，请重新输入"
服务器异常（5xx）  → "服务器繁忙，请稍后重试"
每次提交前自动清空上次错误
```

### 拦截器白名单
`api/client.ts` 中响应拦截器对 `/auth/login` 的 401 不触发跳转，
避免密码错误时被全局 401 逻辑直接刷新页面。

### Modal 弹窗
使用 `App.useApp()` 的 `modal` 实例而非 `Modal.info()` 静态方法，
确保在 antd 5 context 中正确渲染。
