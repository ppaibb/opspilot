综合评定指出工程底座偏薄：调试文件残留、原生 `fetch` 绕过 axios 鉴权、前端零测试、巨型文件、依赖浮动、无 CI/部署产物。本轮按「本周/本月/持续」清单落地（Git 初始化与密钥治理按要求暂缓）。

### 1. 清理调试残留

### 2. 前端鉴权旁路修复
裸 `fetch` 一律改走带鉴权的通道：
- JSON 接口 → `@/api/client`（axios，自动 Bearer + 401 跳转 + 风险票据）

  - `components/ComponentDetailDrawer`、`components/DeploymentProgressModal`
- 流式/SSE → `@/lib/fetch` 的 `authenticatedFetch`（原先死代码，现已接通）
  - `components/ClusterLiveFeed`、`pages/monitoring/logs`、`pages/ai/workbench`
- 顺带：
  - 移除未使用依赖 `recharts`（全项目只用 echarts）
  - `TerminalModal` 去掉硬编码默认 IP/主机名
  - 修正 `TerminalModal` 的 eslint-disable 规则名与位置

### 5. clusters.py 按域拆分
原 `backend/app/api/clusters.py`（约 5920 行）拆为 `backend/app/api/clusters/` 包：

| 模块 | 行数 | 职责 |
|---|---:|---|
| `__init__.py` | 249 | 导出 router/ws_router + 185 个 re-export + mock.patch 兼容 shim |
| `_router.py` | 8 | 共享 APIRouter（避免循环 import） |
| `_schemas.py` | 130 | Pydantic 模型 |
| `_shared.py` | 1171 | 客户端缓存 / YAML / 诊断 / 指标解析 |
| `ws_session.py` | 143 | K8s WS 一次性会话 |
| `cluster_mgmt.py` | 659 | 集群 CRUD / health / audit |
| `nodes.py` | 683 | 节点 / 指标 / drain |
| `workloads.py` | 838 | 工作负载操作 |
| `resources.py` | 1021 | 通用资源 / YAML apply / search |
| `namespaces.py` | 260 | 命名空间 |
| `pods.py` | 1023 | Pod / PVC / Ingress / logs+exec WS |

路由数量 57 REST + 2 WebSocket，路径与 `require_risk_ack` 参数逐字保留。  
`from app.api.clusters import router, ws_router` 及测试用内部符号 re-export 保持兼容（含 `mock.patch.object(clusters, ...)` 的 setattr 同步）。

**踩坑备忘**：
- 契约测试 monkeypatch 的是**包** `app.api.clusters`，拆分后必须 late-bind / setattr-sync 到实现模块，否则 mock 静默失效
- `KUBECONFIG_DIR` 移入子包后要多一级 `dirname`，否则集群全部 404
- 同 arity 路径仍要注意注册顺序：`/nodes/metrics` 先于 `/nodes/{name}`
