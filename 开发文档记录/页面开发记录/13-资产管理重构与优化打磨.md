# 13 - 资产管理重构与后端接口全量落地

> 完成时间：2026-08-04

---

## 页面与后端变更概述

根据企业级资产管理规范与产品设计调整，对资产管理 4 大核心页面（主机、虚拟机、域名、证书）进行全面重构，并同步在 Python FastAPI 后端 (`backend/app`) 全量实现了虚拟机克隆 API 与证书双模式分发部署 API。

---

## 核心改动明细

### 1. 虚拟机管理 (`/assets/vms`) 研发
- **移除分组侧边栏**：按规范明确“虚拟机无需分组，仅纳管为物理/逻辑主机后才具备分组属性”，还原清晰的单列表格大盘。
- **独立虚拟机克隆功能 (`POST /api/vms/{id}/clone`)**：
  - 前端：在表格操作列增加「克隆」按钮（`<CopyOutlined />`），弹出 Modal 自动填充默认名称并调用 `vmsApi.clone(id, name)`；
  - 后端：在 `backend/app/schemas/vm.py` 增加 `VMCloneRequest` 模型；在 `backend/app/api/vms.py` 实现独立的 `clone_vm` 处理逻辑，自动查询 PVE 集群可用 VMID 发起物理/逻辑克隆并新建资产落库。
- **顶部概览统计卡片**：展示虚拟机总数、运行中、已停止及 CPU 总算力核数。

### 2. 证书管理 (`/assets/certificates`) 研发
- **顶部概览统计卡片**：集成证书总数、有效证书数、即将到期 (30天内)、自动续期开启数。
- **证书分发部署双模式 (`POST /api/certificates/{id}/deploy`)**：
  - 前端：`DeployModal` 提供「主机 / Nginx 模式」与「云服务 (CDN / ALB) 模式」动态切换；
  - 后端：升级 `backend/app/api/certificates.py` 的 `CertificateDeployRequest` 与 `deploy_certificate` 函数：
    - **主机模式**：使用 Paramiko SSH/SFTP 上传 PEM 文件并执行 `post_script` 热重载命令；
    - **云平台模式**：校验云账号 API 密钥凭证，自动完成云端 CDN / ALB 证书替换推送并记入系统审计。
- **防御展示**：部署目标 Tag 区分、SAN 备用域名列表无数据时使用 `-` 优雅展示。

### 3. 主机与域名管理 (`/assets/hosts`, `/assets/domains`) 细节打磨
- 集成概览统计卡片、批量分组分配引导及空值防御保护。
