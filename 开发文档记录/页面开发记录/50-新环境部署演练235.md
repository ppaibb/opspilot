## 三、演练抓出的三个真 bug（全部已修）

三个都藏在「只有真全新环境才会走到」的路径上——既有测试、99 环境都没暴露：

### 3.1 offline 的 alloy 配置缺 `targets`，监控栈一启动 Alloy 就崩溃循环

`deploy/offline/monitoring/config/alloy.alloy` 的 `loki.source.docker "docker"` 没写
**必填属性 `targets`**（alloy v1.x 强校验，缺失直接启动失败），容器无限重启，
指标/日志采集全无。`deploy/monitoring/config/alloy.alloy` 那份本来就带
`discovery.docker`（99 上跑的正是它），只有 offline 副本漏了。

**修复**：offline 配置补上 `discovery.docker "containers"` + `targets = discovery.docker.containers.targets`，
与已验证的写法对齐，并在注释里钉死「targets 必填，缺失启动即崩」。

### 3.2 VLogs v1.50 的 field_names 强制要求 `query` 参数，日志页标签下拉整体 502

后端 `POST /api/monitoring/logs/fields` 枚举字段名时只发 `start/end`，而 VLogs v1.50
的 `/select/logsql/field_names` **缺 `query` 直接 400**，后端翻译成 502——日志页的
「主机/服务/任务/级别」下拉全部拉不到值。**99 环境同样存在**（同版本 VLogs），只是
没人点过这个下拉。`field_values` 分支本来就带 `query`，只有 field_names 分支漏了。

**修复**：field_names 参数补 `"query": "*"`（match-all）；新增契约测试
`tests/test_monitoring_logs_fields_contract.py` **3 例**钉死上游参数
（field_names 带 query、field_values 带 field+query+limit、未配置返回 configured=False）。

### 3.3 容器内注册的本机资产 IP 是 Docker 网桥地址，host-metrics 对不上资产

后端首启 `ensure_localhost_asset()` 用 UDP 探测默认出口 IP——后端跑在容器里时拿到的是
**网桥 IP（172.19.0.3）**，而 Alloy 的 `HOST_INSTANCE` 用的是 `MONITORING_HOST`
（192.168.3.235）。compose 注释里明确写了「HOST_INSTANCE 必须与资产表本机 IP 一致，
否则 host-metrics / 日志 host 过滤对不上」，首注册这条路径把它打破了。

**修复**：`MONITORING_HOST` 优先作为本机资产 IP（排除 127.0.0.1/localhost/http:// 形式），
UDP 探测降级为兜底；已存在资产不覆盖的幂等语义不变。235 上验证重注册为
`192.168.3.235`，Grafana 序列 `up{instance="192.168.3.235", job="opspilot-node"}` 正确。

## 五、环境差异备忘（下次部署照抄）

1. **Docker registry 镜像加速必配**：CN 环境直连 `registry-1.docker.io` 超时，
   `/etc/docker/daemon.json` 配 `"registry-mirrors": ["https://docker.m.daocloud.io",
   "https://docker.1ms.run", "https://dockerproxy.net"]`。
2. **`deploy/offline/images/` 里的离线镜像是快照**（本次是 2026-09-23 的），里面没有
   最新代码。要么重新 `package.sh`，要么像这次一样在有网的新机上直接构建。
   别拿旧镜像部署还以为带新功能。
3. **apt 也换国内源**，Ubuntu 22.04 改 `/etc/apt/sources.list`（瘦源格式则是
   `/etc/apt/sources.list.d/ubuntu.sources`）。
4. **外部凭据型功能不在本次验收范围**（非部署问题，是密钥问题）：AI 平台（要配 LLM
   API）、飞书 IM（要 app_secret）、阿里云费用（要 AK/SK）。平台侧页面/接口均可用，
   凭据配好即通。
5. install.sh 交互模式同样可用；非交互走 `--config`，模板见本文第二节字段清单。
