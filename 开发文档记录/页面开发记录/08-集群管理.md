# 集群管理开发记录

**路由**：`/assets/clusters`  **接口**：`/api/clusters`
**状态**：✅ 完成（纳管 + 解除 + 健康摘要）

---

## 功能说明

| 功能 | 说明 |
|---|---|
| 集群列表 | 节点数、Pod 水位、CPU/内存、状态、纳管时间 |
| 两步纳管 | 粘贴 Kubeconfig → `POST /clusters/scan` 探测回填 → 确认纳管 |
| 解除纳管 | 高危确认删除，不影响真实集群 |

## 关键设计

- 状态码：connected/disconnected/unknown/pending，Badge 展示
- Pod 水位用 Tag 色区分（>80% 红，>60% 橙，否则绿）
- scan 接口自动回填 version/node_count/pod_capacity/pod_usage/cpu/mem，用户可手改后确认

## ClusterCreate 必填字段

`name, provider, version, node_count, pod_capacity, pod_usage, cpu_cores, mem_gb, kubeconfig_ref`
（前端固定传 `kubeconfig_ref="managed"`，yaml 由后端解析存储）
