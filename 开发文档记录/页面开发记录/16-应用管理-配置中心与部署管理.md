# 应用管理 — 配置中心与部署管理

> 补齐应用管理模块的「配置中心」和「部署管理」两个子页面，形成完整的应用全生命周期管理能力。

---

## 📋 功能概述

### 1. 配置中心 (`/apps/config-center`)

**核心价值**：
- 集中管理应用环境变量与敏感配置
- .env 文件导入（支持覆盖/跳过/询问模式）
- 配置版本历史与版本对比
- 凭证引用（密码不落地）

**主要功能**：
- ✅ 应用选择器（下拉切换）
- ✅ 配置列表表格（Key/Value/环境/类型/密钥标记）
- ✅ 新增/编辑配置（Drawer 表单）
- ✅ 删除配置（二次确认）
- ✅ .env 导入（Modal + 冲突模式选择）
- ✅ 版本历史（Drawer + 新旧值对比）
- ✅ 环境筛选（全部/开发/测试/生产）
- ✅ 关键词搜索（Key 模糊匹配）

**技术实现**：
- 后端 API：`GET /api/applications/{app_id}/configs`、`POST/PUT/DELETE`、`POST /import`、`GET /{config_id}/revisions`
- 状态管理：`@tanstack/react-query` + `useQuery` / `useMutation`
- UI 组件：antd `Table` + `Drawer` + `Form` + `Modal` + `Select`
- 密钥展示：类型为 `secret` 时显示 `****`，点击可查看原文

---

### 2. 部署管理 (`/apps/deployment`)

**核心价值**：
- 发布记录全景视图（跨应用/跨环境）
- 版本追溯与故障复盘
- 失败发布重试

**主要功能**：
- ✅ 发布记录列表（应用/环境/版本/状态/操作人/时间/耗时）
- ✅ 多维筛选（应用/环境/状态）
- ✅ 发布详情抽屉（版本信息/目标主机/执行日志/耗时）
- ✅ 重试失败发布（高危操作二次确认）
- ✅ 状态标签视觉区分（成功/失败/进行中/已回滚）
- ✅ 分页加载（前端分页）

**技术实现**：
- 后端 API：`GET /api/applications/releases`、`GET /releases/{release_id}`、`POST /releases/{release_id}/retry`
- 状态管理：`@tanstack/react-query` + `useQuery` / `useMutation`
- UI 组件：antd `Table` + `Select` + `Drawer` + `Tag` + `Popconfirm`
- 筛选逻辑：客户端内存筛选（后端返回全量数据）

## 🎯 设计决策

### 为什么保留三个菜单？

1. **后端 API 已就绪**：配置管理和发布记录的 API 都已完整实现
2. **符合 DevOps 标准**：应用目录 + 发布流水线 + 配置中心是企业运维平台的三大支柱
3. **用户心智清晰**：
   - **应用列表** = 应用元数据（名称、负责人、环境、资源绑定）
   - **部署管理** = CI/CD 发布历史与版本追溯
   - **配置中心** = 环境变量与敏感配置的集中管理

### 配置中心 vs 应用详情的配置 Tab

- **配置中心**：跨应用视图，快速切换不同应用的配置
- **应用详情**：单应用上下文，配置与实例/资源/发布历史并列展示
- 两者互补，非重复

## 📝 API 依赖

### 配置中心
```
GET    /api/applications                          # 应用列表（下拉选择器）
GET    /api/applications/{app_id}/configs         # 配置列表
POST   /api/applications/{app_id}/configs         # 新增配置
PUT    /api/applications/{app_id}/configs/{id}    # 更新配置
DELETE /api/applications/{app_id}/configs/{id}    # 删除配置
POST   /api/applications/{app_id}/configs/import  # 导入 .env
GET    /api/applications/{app_id}/configs/{id}/revisions  # 版本历史
```

### 部署管理
```
GET  /api/applications/releases                   # 发布记录列表
GET  /api/applications/releases/{release_id}      # 发布详情
POST /api/applications/{app_id}/releases/{release_id}/retry  # 重试发布
```

## ⚠️ 注意事项

1. **密钥字段保护**：类型为 `secret` 的配置项默认显示为 `****`，点击 Eye 图标才显示明文
2. **高危操作确认**：删除配置、重试发布都需要二次确认
3. **环境隔离**：配置筛选默认按环境隔离，避免误操作生产配置
4. **版本历史**：配置修改自动记录版本，支持新旧值对比
5. **权限控制**：后续需对接 RBAC（`action.applications.configs.edit` / `action.applications.releases.retry`）
