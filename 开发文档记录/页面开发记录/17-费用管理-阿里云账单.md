# 费用管理：阿里云账单（第一版）

> 创建日期：2026-09-17  
> 状态：P0 全部完成（后端账单同步 + 三个前端页面 + 权限 + 定时任务）

## 📊 功能总结

CMDB 新增**费用管理**模块，第一版只对接**阿里云**。通过 BSS OpenAPI（费用与成本中心）
将实例账单落库到本地，提供费用总览、账单明细、云账号管理三个页面。

架构设计参考了开源项目 [CloudExplorer（飞致云）](https://github.com/1Panel-dev/CloudExplorer)
的 finance-management 服务（provider 抽象 + 按日拉取 + 统一账单模型），代码为自行实现。

**核心链路**：
```
凭证保险箱(AK/SK) → 云账号绑定 → 定时/手动同步(DescribeInstanceBill 按天分页)
→ cloud_bills 表(幂等 upsert) → 聚合查询 → ECharts 总览 + 明细表
```

## 后端实现

### 数据模型（`app/models/finance.py`）

**1. `cloud_accounts` 云账号表**
| 字段 | 说明 |
|---|---|
| `credential_ref` | 关联 credentials 表的 AK/SK 凭证（不重复存密钥） |
| `vendor_account_id` | 阿里云主账号 UID（首次同步自动发现） |
| `status / status_message` | pending / active / error + 最近一次校验提示 |
| `last_sync_at` | 最近一次同步完成时间 |
| `enabled` | 是否参与每 6 小时自动同步 |

**2. `cloud_bills` 账单明细表**
- 按 **DAILY 粒度**落库（与 CloudExplorer 同策略）
- 关键字段：账期、出账日期、产品编码/名称、付费方式（预付费/后付费）、
  计费项、实例 ID、资源名、资源组、财务单元、标签、优惠后费用等金额五项
- 唯一约束 `(account_id, billing_date, dedup_key)` 兜底防重

**3. `bill_sync_runs` 同步记录表**：账号 × 账期 × 状态 × 落库行数 × 错误信息

### 同步服务（`app/services/bill_sync.py`）

- **拉取方式**：`DescribeInstanceBill`（BSS OpenAPI 2017-12-14 新版接口），
  `Granularity=DAILY`，逐日循环 + `NextToken` 分页（每页 300，页间 0.15s 防限流）
- **幂等策略**：同一账号同一出账日**先删后插**——阿里云账单约延迟 1 天出账，
  当月重复同步会拿到修正后的金额，直接覆盖安全
- **当月只拉到今天**：未来日期无数据，跳过无效请求
- **凭证解析**：复用与资产云导入相同的 JSON / key=value 双格式 AK/SK 解析
- **错误友好化**：SignatureDoesNotMatch / 缺 BSS 权限 / 限流等常见错误翻译成中文提示
- **手动同步**：独立线程执行（与部署异步化同模式），API 立即返回，前端轮询同步记录
- **定时同步**：`start_bill_sync_runner` 每 6 小时刷新所有启用账号的当月 + 上月
- **并发保护**：每账号一把锁，同账号同步串行、不重叠

### API（`app/api/finance.py`，前缀 `/api/finance`）

| 接口 | 说明 | 权限 |
|---|---|---|
| `GET /credentials-options` | 可绑定 AK/SK 凭证下拉（按用户可见性过滤） | 登录 |
| `GET /accounts` | 云账号列表 | `module.finance.overview` |
| `POST /accounts` | 新增（创建即校验凭证，失败不阻断） | `action.finance.accounts.manage` |
| `PUT /accounts/{id}` | 编辑（换凭证后自动重新校验） | `action.finance.accounts.manage` |
| `DELETE /accounts/{id}` | 删除（连带清除账单与同步记录） | `action.finance.accounts.manage` |
| `POST /accounts/{id}/verify` | 重新校验 AK/SK | `action.finance.accounts.manage` |
| `POST /accounts/{id}/sync` | 手动同步（默认当月+上月，线程异步） | `action.finance.sync` |
| `GET /accounts/{id}/sync-records` | 同步记录（最近 N 条） | 登录 |
| `GET /overview` | 总览聚合：本月/上月总额、环比、按账号/产品/付费方式聚合、日趋势、近 6 月趋势 | `module.finance.overview` |
| `GET /bills` | 账单明细分页（月份/账号/产品/付费方式/关键词筛选，关键词覆盖实例 ID/资源名/计费项/产品） | `module.finance.overview` |
| `GET /bills/group-by` | 按维度聚合（product/instance/billing_item/region/subscription） | `module.finance.overview` |

### RBAC（`app/core/rbac.py`）

## 前端实现

### 菜单与路由

- 顶级菜单「费用管理」（`AccountBookOutlined`），位于监控中心之后
- `/finance/overview` 费用总览 · `/finance/bills` 账单明细 · `/finance/accounts` 云账号
- 面包屑、全局搜索（Ctrl+K）自动生效（共享 menuConfig 扁平路由）

### 1. 费用总览 `/finance/overview`

- 三张统计卡：本月总消费（含环比箭头与百分比）、上月总消费、本月日均（已出账天数）
- **日消费趋势**折线（ECharts 面积图）+ **产品费用占比**环形图（Top 12）
- **近 6 个月消费趋势**柱状图 + 产品费用 Top 表 + 账号消费排名表
- 月份选择器（禁选未来月）+ 账号筛选；无账号时引导跳转云账号页
- 图表按 AGENTS.md 约定使用 echarts-for-react

### 2. 账单明细 `/finance/bills`

- 筛选：月份、账号、产品（由 group-by 动态生成选项）、付费方式、关键词
- 统计卡：筛选结果合计 / 账单行数 / 账期
- 表格列：日期、账号、产品、计费项、付费方式（Tag）、实例/资源、地域、费用（默认降序）
- 服务端分页（50/页），金额合计随筛选联动

### 3. 云账号 `/finance/accounts`

- 列表：名称、云厂商、绑定凭证、云账号 UID（脱敏展示可复制）、状态（校验错误信息 Tooltip）、
  自动同步开关状态、最近同步时间
- 操作：**同步**（手动触发当月+上月）、**校验**（重新验证 AK/SK）、**同步记录**（抽屉，running 时 3s 轮询）、
  编辑、删除（Popconfirm 提示连带删除账单数据）
- 新增/编辑抽屉：账号名 + AK/SK 凭证下拉（仅当前用户可见的凭证）+ 自动同步开关
- 按钮全部接 `usePermission().has()` 权限控制

## 使用指南（首次接入）

1. 在 `资产管理 → 凭证管理` 创建 AK/SK 类型凭证（内容支持 JSON 或 key=value 格式）；
   建议在阿里云 RAM 中单独建子账号并只授予 `AliyunBSSReadOnlyAccess` 只读策略
2. 进入 `费用管理 → 云账号` 新增账号并绑定该凭证，创建时自动校验
3. 点击「同步」拉取账单（首次同步当月 + 上月；历史月份可通过同步接口指定 `billing_cycle`）
4. 前往「费用总览」「账单明细」查看数据；之后每 6 小时自动刷新

**限制说明**：阿里云 BSS 仅支持查询**近 18 个月**账单；账单约延迟 1 天出账，
当月数据每天滚动更新。
