## 一、费用 × CMDB 联动

**关键洞察**：阿里云云导入的资产直接以 ECS 实例 ID（`i-xxx`）作为 `asset.instance_id`，
与 `cloud_bills.instance_id` 天然对齐——**不需要中间映射表**，一个聚合接口即可打通。

### 后端 `GET /api/finance/instance/{instance_id}/cost?months=6`

- 近 N 月月度费用序列（默认 6，上限 18 = BSS 可查窗口）
- 本月 / 上月总额（环比由前端计算展示）
- 本月计费项构成 Top 8（名称/金额/占比）
- `matched` 标记：账单无此实例时明确返回，前端据此展示空态引导

### 前端

- `components/InstanceCostDrawer.tsx`：费用摘要（本月/上月/环比箭头）+ 月度柱状图 + 计费项构成表；
  未匹配时说明可能原因（自建主机 / 未纳管 / 未同步）
- 主机管理页「更多」下拉新增**实例费用**入口（按 `module.finance.overview` 权限显隐）

## 二、预算告警

### 后端

**配置存储**：`system_configs.finance_budget_config`（JSON，避免为单个配置建表）：
`monthly_budget / warn_ratio(0.8) / critical_ratio(1.0) / enabled / updated_at`

**接口**：
- `GET /api/finance/budget` — 配置 + 当月实时使用（spent / usage_ratio）一次拉齐
- `PUT /api/finance/budget` — 保存（校验：critical ≥ warn；启用时预算必须 > 0）；权限 `action.finance.accounts.manage`

**告警 runner**（`services/budget_alert.py`，与证书到期告警完全同模式）：
- 每 1 小时聚合当月账单总额 vs 预算：
  - 达 critical → `critical` 级 firing 事件（文案含预算/已花/百分比）
  - 达 warn → `warning` 级 firing
  - 回落 → `resolved` 事件（自动关闭历史告警）
- 复用 `dispatch_active_alerts` 管道：静默/路由/防抖/active_alerts 落库/渠道推送全部继承
- 合成规则 ID：`builtin-finance-budget`（「云费用预算超支」）

### 前端（费用总览页）

- 顶部改四卡：总消费 / 上月 / 日均 / **预算使用卡**——启用时显示「已花 / 预算」+ 进度条
  （正常蓝 / 超警告橙 / 超严重红）；未启用显示引导文案
- 预算设置抽屉：预算额、警告/严重阈值、启用开关（`action.finance.accounts.manage` 权限）

## 三、实时看板升级（/monitoring/live）

替换原「只能单主机逐台看」的版本：

**全局模式（默认）**——消费既有 `/monitoring/dashboard` 聚合接口（此前无前端使用方）：
- 四统计卡：采集目标 / 在线 / 离线 / 活动告警
- 四张平台级时序图：CPU、内存、磁盘（均值实线 + P95 虚线）、网络入出（MB/s）
- 资源占用 Top 主机表（CPU/内存超阈值红字）
- 采集目标状态列表（在线灯 + provider/region）
- 30 秒自动刷新

**主机对比模式**：
- 多选主机（上限 4 台防序列过密）并行拉取 `/host-metrics`
- CPU / 内存两张多序列对比图，30 秒刷新

未配置 VictoriaMetrics 时全局模式整体降级提示。
