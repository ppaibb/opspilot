# 41 - 本机内置采集兑现与主机日志抽屉

> 更新时间：2026-09-24

**背景**：用户质疑「本机主机由内置监控栈自动采集，无需手动安装 Agent」是否成立；并指出主机列表「日志」图标与「监控」图标都打开指标抽屉。

**决策**：采用方案 **1B + 2B**（非放开本机安装）。

---

## 1B — 兑现本机内置自动采集

### 问题核查

| 采集物 | 此前声称 | 实际 |
|---|---|---|
| Docker 容器日志 | 内置自动采 | 基本成立（alloy.alloy 有 loki.source.docker） |
| 本机 CPU/内存/网络 | 内置自动采 | **不成立**：默认 scrape targets=[]，无 exporter.unix |
| 离线监控栈 | 同上 | **无 Alloy 服务**（仅 VM+VLogs+Grafana） |
| 主机列表本机状态灯 | 显示正常 | 写死 `local → ok`，与真实数据无关 |

### 改动

1. **`deploy/monitoring/config/alloy.alloy`**
   - 新增 `prometheus.exporter.unix`（`/host/proc` `/host/sys` `/rootfs`）
   - `discovery.relabel` 写入 `instance=HOST_INSTANCE`、`host=HOST_NAME`、`job=opspilot-node`
   - Docker 日志 labels 带 `host` / `instance`，便于按主机过滤

2. **`deploy/monitoring/docker-compose.yml`**
   - Alloy 挂载宿主机 `/proc` `/sys` `/`（只读）
   - 注入 `HOST_INSTANCE`（=`MONITORING_HOST`）、`HOST_NAME`

3. **离线包 `deploy/offline/monitoring/`**
   - compose 增加 `alloy` 服务（镜像 `grafana/alloy:v1.16.3`）
   - 带 `config/alloy.alloy`（与默认模板同步）
   - `install.sh` 启动监控时补齐 `MONITORING_HOST` / `HOST_NAME`
   - `package.sh` 增加拉取/保存 Alloy 镜像
   - `env.example` / README 同步说明；**不要用 wg0 /32 当 MONITORING_HOST**

4. **后端 `GET /targets` 与 `GET /log-targets`**
   - `provider=localhost` 且无 Agent 时返回 `source=builtin` 记录
   - `enabled/status` 以监控连接（vm_url + vlogs_url）是否配置为准
   - 安装拒绝文案改为：「监控栈内置 Alloy 自动采集（host 指标 + Docker 日志）」

5. **前端**
   - 主机列表本机灯不再写死绿灯，改读后端 target
   - 采集车队本机操作列显示「内置采集」Tag，不再提供安装/卸载

### 前置条件（真采到数据）

- 监控栈 Alloy 在跑，且挂载了 docker.sock + host proc/sys
- `HOST_INSTANCE` 与资产表本机 IP 一致（host-metrics 的 `instance=~IP` 才能命中）
- 后端「监控连接」已填 VM / VLogs

---

## 2B — 主机日志抽屉

### 问题

- 主机列表「日志」灯点击打开的是 **HostMetricsDrawer**（指标抽屉）
- 指标抽屉底部「相关日志」跳 `/monitoring/logs?host=`，但日志页**不读**该参数

### 改动

1. **新组件 `frontend/src/components/HostLogsDrawer.tsx`**
   - 与指标抽屉对称：时间窗（15m/1h/6h/24h）+ 刷新 + 最近日志表
   - 查询：`POST /monitoring/logs/query`，`host_ips: [assetIp]`（无 IP 时用 `host_names`）
   - 底部：实时看板 / 相关告警 / Grafana / **完整查询**（带 `?host=`）

2. **主机列表**
   - 日志灯 → `setLogAsset` + `setLogOpen` → HostLogsDrawer
   - 监控灯仍开 HostMetricsDrawer

3. **日志查询页**
   - 读 `?host=`：预填 `labels.host` 并自动执行一次查询
   - 修复指标抽屉「相关日志」深链断参
