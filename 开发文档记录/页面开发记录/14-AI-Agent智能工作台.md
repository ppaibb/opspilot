# 14 - AI Agent 智能工作台全功能落地与 Pro 交互重构

> 完成时间：2026-08-05

---

## 页面与交互特征

全量实现了基于 Ant Design Pro 官方最轻量通透 Chatbot 设计语言的 **AI Agent 智能工作台 (`/ai/workbench`)**。

### 1. 两栏 Ant Design Pro 风格极简 UI 布局
- **左侧会话历史侧边栏 (250px)**：
  - 浅灰底色 `#fafafa`，包含「+ 新建对话」浅蓝柔和按钮（全量接入后端 `POST /api/ai/sessions`）；
  - 历史会话列表呈现与检索（悬浮支持重命名 `PUT` 与删除 `DELETE` Popconfirm）。
- **右侧极简对话与打字机响应区 (Flex 1)**：
  - **Top Bar 无缝状态栏**：动态渲染当前启用的 LLM Model 标签、Agent 在线状态点阵和右侧 `@ 技能索引` 浮窗按钮；
  - **空灵推荐 Prompt 气泡**：未对话时展示极简胶囊按钮，一键问答；
  - **Markdown 富文本解析引擎**：
    - **加粗文本 (`**bold**`)**：自动渲染为 `#0f172a` 600 权重的规范加粗字；
    - **多级无序与有序列表 (`- ` / `1. `)**：自动渲染带有蓝点 `•` 和灰点 `▫` 层次缩进的列表；
    - **标题与行内代码 (`###` 与 `` `code` ``)**：支持大中标题与浅灰高亮行内 Code 标签；
    - **极客代码块 (` ```bash `)**：代码块带黑色极客高亮，支持一键复制代码与一键派发至 WebSSH 伪终端。
  - **@Mention 技能召唤系统**：
    - 底部 Sender 输入框输入 **`@`** 字符自动弹出 `@Mention` 技能下拉选单（含中文/拼音过滤）；
    - 支持点击外部区域 (Click Outside) 或按 `ESC` 键自动关闭选单；
    - 输入框底部包含 `@ 召唤 Skill` 快捷标签；
    - 发送带 `@Skill` 的消息时，自动提炼 `focus_skills` 并与后端 SSE 流强联控！
