# 44 - 资产操作列收进三点菜单

> 更新时间：2026-09-28

## 背景

资产列表操作列按钮过多（证书/虚机 5 个、210px），危险操作与常用操作并排易误点。
对齐主机管理既有模式：**高频主操作外露 + 低频/危险进 `MoreOutlined` 菜单**。

## 改动清单（仅前端）

| 页面 | 外露 | 三点菜单 | 操作列宽 |
|---|---|---|---|
| **证书** | 部署任务 · 续期 · 下载 | **吊销** · **删除**（danger + 确认 + 票据） | 210→130 |
| **虚机** | 开机 · 编辑 | 关机 · 克隆 · **删除** | 210→120 |
| **凭证** | 编辑 | 导出 .pem（仅 SSH Key）· **删除**（引用提示保留） | 180→110 |
| **集群** | 详情 · 健康摘要 | 编辑 · **解除纳管** | 120→110 |
| **域名** | 编辑 | **删除域名** | 120→100 |
| **组网成员** | 配置 · 启/停 | **删除成员** | 210→140 |

- 模式照抄主机页：`Dropdown menu={{ items, onClick }} trigger={['click']}` + `MoreOutlined`
- 危险项 `danger: true`；点击仍走 `modal.confirm` + `useRiskConfirm` 票据，**不降级确认**
- 移除各页因此不再使用的 `Popconfirm` 导入（lint 干净）

## 回归

- lint 0 error / vitest **52** passed / build 通过
- 上线 `opspilot/frontend:1.0.12`，`/` 200

## 人工验证点

- 证书行：点 ⋯ → 吊销/删除出现；删除有确认框
- 虚机行：点 ⋯ → 关机/克隆/删除
- 凭证行：SSH Key 的 ⋯ 里有「导出 .pem」
- 集群行：⋯ → 编辑 / 解除纳管
