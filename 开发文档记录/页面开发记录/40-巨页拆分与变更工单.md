## B. 变更工单

**流程**：申请 → 多级审批 →（变更窗口）→ 执行（高危票据）→ 归档

**后端**
- 模型 `ChangeTicket`（`change_tickets` 表）：类型/风险/影响面/回滚方案/审批链/窗口/执行结果
- API `/api/changes`：`GET /types`、列表/详情、创建、approve/reject/cancel、execute
- 权限：`action.change.submit` / `approve` / `execute`（execute 风险等级 high）
- 自动执行器注册表：`host.delete`、`certificate.delete`；其余类型记工单 + 人工标记 `manual_result`
- 契约测试 `test_change_ticket_contract.py` 6 例

**前端**
- 菜单「运维工具 → 变更工单」`/tools/changes`
- 列表筛选（状态/类型/关键词）+ 新建 Drawer（影响面/回滚/审批链/变更窗口）
- 详情 Modal：审批 Steps、批准/驳回/执行/取消；执行走 `useRiskConfirm('change:execute')`
