# 53 - 数据库工作台布局调整：概览卡下沉与去重（2026-10-09）

> 两轮需求：
> ①「工作台这一页 上面放了四个大卡片，移动到下面去，这样这一个大页面整体布局就一样了」
> ——第一轮从 **Tab 栏上方**移到页底，七 Tab 结构统一（Tab 栏不再随切换跳位）；
> ②「这四个卡片和上面的重复了，我觉得可以去掉？你觉得呢？分析下」→「嗯 就这么做」
> ——第二轮重复性分析后**整行删除**：待审批/待执行与「今日流水线」同源重复
> （「待执行」两处口径还矛盾），数据源/连接异常降级为**条件告警条**（仅异常时出现）。
>
> 检查-全量 **4/4 全绿**，235 已部署并浏览器实证。

---

## 一、第一轮：概览卡压在 Tab 栏上方（布局不一致）

`/assets/databases` 是七个 Tab 的大页面（工作台 / SQL 工单 / 自助查询 / 查询授权 /
数据源 / 审批流 / 审核规则）。原实现里，`tab === 'home'` 时在 **`<Tabs>` 之前**
渲染一行四张统计卡（`index.tsx` 顶部 `Row`）：

```
[数据源][连接异常][待审批][待执行]   ← 只有工作台有，压在 Tab 栏上方
[工作台 | SQL 工单 | ... ]
[工作台内容 ...]
```

两个毛病：

1. **布局不一致**：切到其它六个 Tab，这行卡片消失、Tab 栏上跳贴顶；停在工作台时
   Tab 栏被压到卡片下面——同一大页面里 Tab 栏位置随 Tab 变化，正是「整体布局
   不一样」的来源。这也是全站唯一内容压在 Tab 栏之上的页面。
2. 视线动线断裂：进入页面先看到一排统计，再看到导航，再看到内容。

**第一轮修法**：把 `Row`（四张卡）从 `<Tabs>` 之前**平移到之后**（工作台内容与
定时执行提示之间，仍在 `tab === 'home'` 条件内）：

```
[工作台 | SQL 工单 | ... ]          ← Tab 栏永远在顶
[开工卡]
[今日流水线 × 4]
[我的申请 | 最近工单]
[数据源][连接异常][待审批][待执行]   ← 概览下沉为页底
[定时执行提示（如有）]
```

**第一轮验证**：浏览器几何断言——工作台 / SQL 工单 / 切回三态 `tabsTop` 恒
**112px** 不跳；卡片落在 635px 内容之后；0 失败请求。

## 二、第二轮：概览卡去重删除（同日，需求②确认后）

### 重复性分析（先分析后动手）

| 卡片 | 与上方「今日流水线」的关系 |
|---|---|
| 待审批 | **完全重复**：同源筛选（`pendingCount` vs `pending.length`）、同点击目标（工单列表 pending 筛选） |
| 待执行 | **近似重复 + 口径矛盾**：底部卡数全部已批准（含定时中的），流水线卡**减去**定时中的（单独有「定时中」卡）——有定时工单时两处数字打架（底部 5、顶部 3+定时中 2） |
| 数据源 | 不重复但是资产盘点数据，Tab 栏常驻可点，放工作台跑题（WorkbenchPanel 设计原则：按待办不按工具排布） |
| 连接异常 | 不重复但健康预警——**唯一有保留价值的信号**，降级为条件告警条 |

### 改动

- 四张卡整行删除；`approvedCount` 计算与 `Card/Row/Col/Statistic/PlayCircleOutlined/
  ExclamationCircleOutlined` 等死代码一并清掉（`pendingCount` 保留，SQL 工单 Tab
  角标在用；`DatabaseOutlined`/`SafetyCertificateOutlined` 保留在 Tab 标签上）；
- 新增**条件告警条**：`errorInstanceCount > 0` 时页面底部出红色
  「N 个数据源连接异常，提单/执行会失败」+「去查看」按钮 → 数据源 Tab；
  健康时整条不出现——与下方定时执行提示（`scheduledCount > 0` 才显示）同款模式。

### 最终结构

```
[工作台 | SQL 工单 | ... ]   ← Tab 栏贴顶
[开工卡]
[今日流水线 × 4]              ← 待审批/待执行/定时中/闭环率（唯一计数权威）
[我的申请 | 最近工单]
[连接异常告警条（仅异常时）]
[定时执行提示（仅有时）]
```

### 验证

- 断言：`.ant-statistic` 计数 **0**、`tabsTop` 恒 **112px**、健康态 0 条告警、
  0 失败请求；截图确认四卡消失、页面干净；
- lint 0 error、vitest 52 passed、检查-全量 **4/4 全绿**；235 已重建前端镜像部署。
