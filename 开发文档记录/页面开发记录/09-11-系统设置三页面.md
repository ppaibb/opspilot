# 系统设置三页面开发记录

完成时间：2026-07-28

---

## 09 · 用户管理

**路由**：`/settings/users`  **接口**：`/api/settings/users`

| 功能 | 说明 |
|---|---|
| 用户列表 | 搜索（用户名/姓名/邮箱/部门）、角色 Tag、状态 Badge、最后登录 |
| 新增用户 | 用户名（格式校验）+ 初始密码（≥8位）+ 姓名/邮箱/部门/角色/状态 |
| 修改角色 | 选角色（从 rbac/metadata 动态拉取）+ 展示当前权限摘要 |
| 重置密码 | 两次一致性校验，走高危确认 |
| 启用/禁用 | 行内 Switch，走高危确认 |

---

## 10 · 权限管理

**路由**：`/settings/permissions`  **接口**：`/api/settings/rbac/`

| 功能 | 说明 |
|---|---|
| 角色列表 | 系统内置角色（橙色标签）+ 自定义角色，显示权限数角标 |
| 新增权限组 | 角色标识（只能创建时设，之后不可改）+ 描述 + 权限配置 |
| 编辑权限 | 系统角色：可改描述和权限，不可改标识；自定义角色：全部可改 |
| 删除 | 只有 `deletable=true` 的自定义角色显示删除按钮 |
| 权限配置面板 | Collapse 按分组折叠，支持分组全选（Indeterminate 半选态），每项带 key 提示 |

---

## 11 · 审计日志

**路由**：`/settings/audit`  **接口**：`GET /api/settings/audits`

| 功能 | 说明 |
|---|---|
| 日志列表 | 时间（默认降序）、操作人、操作、操作对象（省略+Tooltip）、IP、结果、风险等级 |
| 四维筛选 | 搜索操作/资源 + 操作人下拉（动态）+ 结果 + 风险等级 |
| 分页 | 默认 50 条，支持 50/100/200 |
| 高危行高亮 | 通过 `rowClassName` 打 `ant-table-row-danger` 类，CSS 层控制颜色 |

## 公共改善

### GroupSidebar 公共组件

**文件**：`components/GroupSidebar.tsx`

功能：
- 分组筛选（点击切换）
- 新增/编辑/删除分组（ColorPicker 色块 + Modal）
- 显示各分组成员数
- 选中行后出现"分配到分组"快捷操作
- 接受 `resourceType` prop，支持 host/vm 等不同资源类型

接入：主机管理、虚机管理

### 全局 Query 错误提示

**文件**：`App.tsx` → `QueryCache.onError`

| 错误类型 | 提示文案 |
|---|---|
| 网络不通/超时 | 网络连接出现问题，请检查网络后重试 |
| 502/503/504 | 服务暂时不可用，请稍后重试 |
| 5xx | 出了点问题，请刷新页面或联系管理员 |
| 403 | 没有访问权限 |

用 `GlobalErrorHandler` 组件桥接 antd `message` 实例（QueryCache 在 React 树外，无法直接用 hooks）。
