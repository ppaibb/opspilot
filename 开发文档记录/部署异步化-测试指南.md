### 用例 2：查询任务状态（API 测试）

**步骤**：
```bash
# 1. 创建部署任务
curl -X POST http://localhost:8001/api/applications/{app_id}/components?async_deploy=true \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "name": "test-compose",
    "deployment_type": "docker_compose",
    "create_mode": "deploy",
    "resource_refs": ["host:xxx"],
    ...
  }'

# 记录返回的 task_id

# 2. 查询任务状态
curl http://localhost:8001/api/applications/tasks/{task_id} \
  -H "Authorization: Bearer YOUR_TOKEN"

# 3. 查询应用的任务列表
curl http://localhost:8001/api/applications/{app_id}/tasks \
  -H "Authorization: Bearer YOUR_TOKEN"
```

**预期结果**：
- ✅ 第一个请求返回：`{ task_id: "xxx", status: "pending", message: "..." }`
- ✅ 第二个请求返回完整任务信息（包含进度、状态、日志）
- ✅ 第三个请求返回任务列表（最多 10 条）

## 🐛 已知问题

### 1. 模拟实现
- **问题**：当前使用 `time.sleep(2)` 模拟部署
- **影响**：不会真正执行 Docker Compose 部署
- **解决**：对接 runtime.py 的 `_deploy_new_runtime_instance` 逻辑

### 2. 站内通知未实现
- **问题**：`create_notification` 是空函数
- **影响**：部署完成后不会发送通知
- **解决**：对接真实的站内通知 API

### 3. Request 对象缺失
- **问题**：后台线程无法访问原始 Request
- **影响**：审计日志可能缺少请求信息
- **解决**：提取必要信息存入 deployment_config
