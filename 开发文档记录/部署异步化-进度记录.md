## 📝 技术要点

### 后端技术
1. **线程安全**：使用独立的 DB Session
2. **异常处理**：所有异常都要捕获并记录
3. **进度更新**：每个关键步骤都要更新进度
4. **日志记录**：output_log 累积所有执行日志

### 前端技术
1. **轮询策略**：useQuery refetchInterval
2. **进度展示**：antd Progress 组件
3. **状态管理**：完成后自动关闭，刷新列表
4. **错误处理**：失败时展开详细信息

### 数据库
1. **索引优化**：status、app_id、created_at
2. **JSONB 存储**：deployment_config 灵活存储配置
3. **级联删除**：应用删除时级联删除任务

## ⚠️ 已知问题

1. **Request 对象传递**
   - 后台线程中无法直接使用原始 Request
   - 需要提取必要信息或重构代码

2. **数据库连接池**
   - 后台线程使用独立 Session
   - 需要正确关闭连接避免泄漏

3. **通知 API 未实现**
